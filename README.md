# Python Finance and Data Projects

Small, runnable examples of data processing, quantitative finance and business reporting in Python.

| Project | What it shows | Tools |
|---|---|---|
| [01_ohlcv_pipeline](01_ohlcv_pipeline) | Resampling 1m to 5m candles, EMA/RSI/ATR/VWAP | pandas, NumPy, matplotlib |
| [02_options_iv_greeks](02_options_iv_greeks) | Black-Scholes pricing, Greeks, implied volatility | NumPy, SciPy |
| [03_outlet_mis_report](03_outlet_mis_report) | Automated Excel MIS report for a food outlet | pandas, openpyxl |

## Setup
```
pip install -r requirements.txt
```

All data is synthetic. Examples are educational and are not investment advice.
